# Plushie images

Drop plushie image files into this folder. The app watches it (and rescans on
startup) and automatically creates a plushie entry for each new image.

Supported formats: `png`, `jpg`, `jpeg`, `gif`, `webp`, `svg`, `avif`, `bmp`.

File names become the initial plushie name
(e.g. `cocoa-bunny.png` → "Cocoa Bunny"). Set the rarity, description, and
series from the admin page (`/admin`), or use the "Rescan images" button to pick
up newly added files.
